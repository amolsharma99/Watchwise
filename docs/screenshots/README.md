# Screenshot provenance

These screenshots show **demonstration data** rendered from Watchwise's shipped `sidepanel.html` and `sidepanel.css`, plus a goal-toast demonstration styled to match `content.js`. They are not screenshots of a user's history, a live Gemini result, or a third-party video. The synthetic titles and totals are illustrative.

To regenerate the HTML fixtures, run `python3 tools/render_demo_screenshots.py` from the repository root. Render each fixture in an isolated browser profile at exactly 640×400. The store accepts 640×400 or 1280×800 screenshots, up to five; use images 01–05 for the listing. Image 06 is a guide-only close-up. Review the images against the current extension UI before uploading; replace them with live, sanitized screenshots when available.
