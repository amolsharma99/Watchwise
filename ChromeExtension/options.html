Privacy and tracking essentials

Site access disclosure

Watchwise requests access to HTTPS pages so it can detect visible HTML5 video elements across sites and embedded frames. After you opt in, it records only basic playback telemetry. It never captures pixels, audio, captions, arbitrary page-body text, cookies or form contents. Titles come only from media attributes, Media Session, page title metadata and, on Netflix /watch/ pages, exact player-title metadata.

With AI consent, Watchwise sends the public YouTube URL and analysis instructions directly to Google Gemini using your saved key, and requests may consume your quota. The key stays in local extension storage except when it is sent over HTTPS to Google for an analysis you allowed.

On a standard YouTube video, Summarise in Gemini AI Studio is a separate, user-initiated action. It opens a new Studio chat and inserts a prepared prompt containing the public video URL. You review and press Run; Watchwise does not submit it or read the result. Google’s Studio page can access the prompt once inserted.

Automatic analysis starts only for a visible, active public YouTube video when playback begins. It is paused by Movie Mode, exclusions, missing AI consent, or a missing API key. Watchwise deduplicates each video locally; the separate Studio button remains available when this is off.
