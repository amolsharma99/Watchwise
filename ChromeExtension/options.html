Privacy and tracking essentials

Site access disclosure

Watchwise requests access to HTTPS pages so it can detect visible HTML5 video elements across sites and embedded frames. After you opt in, it records only basic playback telemetry. It never captures pixels, audio, captions, page body, cookies or form contents.

Automatic analysis starts only for a visible, active public YouTube video when playback begins. It is paused by Movie Mode, exclusions, missing AI consent, or a missing API key. Watchwise deduplicates each video locally; you can turn this off without disabling manual analysis.
