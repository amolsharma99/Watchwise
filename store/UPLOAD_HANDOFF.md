# Chrome Web Store upload handoff

This handoff is for the **local-only Watchwise v0.4.0 edition**. The Gemini-enabled v0.3.9 development ZIP must not be uploaded as the public item. Uploading and submitting in the Chrome Web Store Developer Dashboard must be done by the owner in Chrome; the available browser surface does not allow scripting the extensions gallery.

## Files and fields

- **ZIP:** `ChromeExtension/dist/watchwise-local-v0.4.0-store.zip` (generated by `ruby ChromeExtension/scripts/package_local_store.rb --output ChromeExtension/dist/watchwise-local-v0.4.0-store.zip` after validation).
- **Screenshots:** `store/screenshots/01-overview.png` through `05-interruption-controls.png`, in that order. Each is 640×400. They contain synthetic demonstration data, as disclosed in [screenshots/README.md](screenshots/README.md). Do not upload screenshot 06; it is for the guide.
- **Listing, privacy declarations, permission reasons, and reviewer test instructions:** copy from [LISTING.md](LISTING.md).
- **Public privacy-policy URL:** `https://github.com/amolsharma99/Watchwise/blob/main/store/PRIVACY.md` (published and verified).
- **Public illustrated guide:** `https://github.com/amolsharma99/Watchwise/blob/main/store/USER_GUIDE.md` (published and verified). Support issues at `https://github.com/amolsharma99/Watchwise/issues`.

## Dashboard steps

1. Sign in to the [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole/). Complete developer registration and 2-Step Verification if Google requires them.
2. Add a new item and upload the local-only v0.4.0 ZIP above. Confirm the dashboard reads **Watchwise 0.4.0** and its permissions are `scripting`, `sidePanel`, and access to HTTPS sites. Stop if it shows Gemini, an API-key field, or a different package version.
3. Fill the Store Listing and Privacy tabs using [LISTING.md](LISTING.md). Add screenshots 01–05, the public privacy URL, and reviewer test instructions. Choose **Public** distribution.
4. Review the dashboard's warnings and submit for review. Record the item ID and review status. When Google approves it, record the public listing URL and check the installed Store edition in Chrome.

The Store install will have a different extension ID and fresh history. If the unpacked development copy is still installed, export its history first if wanted, clear its Gemini key if no longer used, and disable it before trying the Store edition to prevent duplicate nudges. There is no import into the Store edition.
