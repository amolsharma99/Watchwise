# Watchwise Store icon candidate

The eye outline represents watching, and the play triangle represents video. The design retains Watchwise's purple gradient and a simple white symbol. The 128×128 PNG has a 96×96 icon centered within 16 pixels of transparent padding, following the Chrome Web Store icon guidance.

This is a **candidate only**. The signed-off v0.4.0 release ZIP still contains the original white `W` icon. If this candidate is selected, replace the extension's 16, 32, 48 and 128 pixel PNG assets, rebuild and revalidate the ZIP, then upload that new ZIP to the Store. The SVG is an editable source; Chrome's manifest uses the PNG files.

Files:

- `watchwise-eye-play.svg`: editable vector source.
- `watchwise-eye-play-128.png`: Store-size PNG.
- `watchwise-eye-play-16.png`, `watchwise-eye-play-32.png`, `watchwise-eye-play-48.png`: small-size checks and potential extension assets.
